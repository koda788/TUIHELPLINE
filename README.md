# TUI Discord Modmail Bot

A custom Modmail/Ticket system designed for the TUI Discord server.

## Features
- **Direct Message Tickets:** Users can DM the bot to initiate a support request.
- **Department Routing:** Categorized dropdown menu selection (Human Resources, Operations, Publicity Enquiry, General Inquiry).
- **Staff Commands:** Commands including `.reply`, `.areply`, `.sub`, `.unsub`, `.ban`, `.unban`, `.close`.
- **Dynamic Snippets:** Create, edit, and call auto-response snippets directly using `.<snippet_name>`.
